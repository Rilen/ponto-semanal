# Ponto Semanal — Instalação, Uso e Privacidade

Este repositório contém a página informativa, o guia de instalação e uso, a política de privacidade e imagens ilustrativas sintéticas do projeto **Ponto Semanal**.

- Site: https://rilen.github.io/ponto-semanal/
- Guia: https://rilen.github.io/ponto-semanal/guia.html
- Política de Privacidade: https://rilen.github.io/ponto-semanal/privacy.html
- Contato público: https://github.com/Rilen/ponto-semanal/issues

**Em preparação para disponibilização na Chrome Web Store.** O link oficial da loja será divulgado no site quando a extensão estiver publicada.

O Ponto Semanal é uma ferramenta independente de conferência pessoal de horas e planejamento da jornada.

**Não é sistema oficial de ponto e não possui vínculo, endosso, autorização ou representação da Prefeitura de Rio das Ostras, do NewEasy ou do Jubarte.**

Este repositório não contém:

- código-fonte da extensão;
- registros de ponto;
- dados pessoais;
- backups;
- credenciais, cookies ou tokens.

As imagens do guia são ilustrações sintéticas, sem nomes ou registros reais.

## Publicação no GitHub Pages

1. Enviar o commit para a branch principal do repositório público.
2. Abrir **Settings → Pages**.
3. Em **Build and deployment**, selecionar **Deploy from a branch**.
4. Escolher a branch principal (`main` ou `master`) e a pasta **`/ (root)`**.
5. Salvar e aguardar a publicação.
6. Conferir as URLs:
   - `https://rilen.github.io/ponto-semanal/`
   - `https://rilen.github.io/ponto-semanal/guia.html`
   - `https://rilen.github.io/ponto-semanal/privacy.html`

A publicação e o push dependem de autorização do responsável. Este guia está preparado localmente para revisão; não foi publicado automaticamente.
